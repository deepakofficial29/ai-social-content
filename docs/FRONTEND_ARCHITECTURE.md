# Frontend Architecture

The frontend is a React, TypeScript and Vite application using Tailwind CSS, React Router, TanStack Query, Axios and Lucide icons.

Routes:

- `/`
- `/create`
- `/media`
- `/evidence/:collectionId`
- `/studio/:collectionId`
- `/history`

API modules are under `frontend/src/api`, reusable shell and state components under `frontend/src/components`, and workflow pages under `frontend/src/pages`.
