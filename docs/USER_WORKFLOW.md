# User Workflow

1. Upload image, carousel, video or audio from Create.
2. Reorder carousel images before upload.
3. Run understanding and open Evidence Review.
4. Inspect direct observations, interpretations, provenance, conflicts and quality.
5. Open Caption Studio and configure the platform, objective, audience, tone and language.
6. Generate grounded variants and inspect warnings and evidence IDs.
7. Copy or regenerate a variant.
8. Open Generation History to review persisted requests.

The interface does not publish to social media.
